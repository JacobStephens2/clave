# UX Flow & Wireframes

## Screen Map
- Splash → Main Menu
- Main Menu → [Play | Deckbuilder | Collection | Shop | Settings]
- Play → Matchmaking/AI Select → Match → Results → Main Menu
- Deckbuilder → Save → Main Menu

## Match Screen Zones
- Opponent area (top)
- Play field (middle)
- Player hand (bottom, fanned)
- Resource/turn HUD
- Inspect overlay

## Touch Interactions
- Tap card: inspect/enlarge
- Long-press: contextual info
- Drag card up: play
- Drag to target: targeting line

## Android Considerations
- Orientation: <portrait/landscape>
- Safe areas / notches / foldables
- Min target size: 48dp
- Back-gesture / back-button behavior per screen
