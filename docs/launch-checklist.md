# Android Launch Checklist

## Play Console
- [ ] App listing (title, short/long description)
- [ ] Feature graphic, screenshots (phone + tablet)
- [ ] Content rating (IARC)
- [ ] Data safety form
- [ ] Privacy policy URL

## Build
- [ ] Release keystore secured
- [ ] Versioning strategy
- [ ] Code shrinking / obfuscation configured
- [ ] Crash reporting integrated

## Soft Launch
- [ ] Target markets selected
- [ ] KPI thresholds defined
- [ ] Kill-switch / remote config

## Legal
- [ ] Art/IP clearance
- [ ] Loot box / gambling disclosures if applicable
- [ ] Third-party license attributions
